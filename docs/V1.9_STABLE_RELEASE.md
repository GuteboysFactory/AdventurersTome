# Adventurer’s Tome 1.9.0

Adventurer’s Tome 1.9.0 brings campaign migration and clearer everyday navigation into one release. It promotes the campaign-tested 1.9 QA line, including the latest UI and window-stability fixes.

## Migration and Import & Export

- A shared Import & Export workspace for campaign ZIPs, Tome packages, session/quest text and player-owned Chronicle transfers. Role-aware entry points keep campaign tools GM-only.
- Portable campaign documents, folders, identity/reference mappings and supported image/audio assets. Missing media is reported; original unavailable files cannot be reconstructed.
- Copy-based migration preserves the source world, retains unmapped source data and presents reviewable target mappings. Interrupted imports retain saved copies for safe retry without duplicating them.
- Account mapping supports existing destination users and proposed new Player accounts. Ownership, private GM data and player Chronicle transfers retain their separate authorization boundaries.
- TAF 3.1.0/3.2.0 → Realm Guard support, exercised with an exported campaign: biography headings and explicit header details, trained skills, Wises, Traits, written Talents, resource counters, lifetime Fate/Persona spending, readable descriptions, images and character contacts. The target system calculates progression from transferred spending.
- Contact recovery offers explicit role-to-person choices when old source links cannot be resolved safely. Missing age or other uncertain values are not invented. Original source information remains available for review.

## Campaign Tools and reading

- A clearer Overview and consistent Memory, Analysis, Index, Player Signals and Assistant layouts, with readable text, panels, filters and responsive navigation.
- Player Signals groups explicitly shared notes by player with counts and last-shared dates. A latest-first feed and cross-player search are available; private player Chronicles remain separate.
- Session Chronicle text now precedes linked quest threads, people, places and characters. Compact link/review counters remain above the story; player Chronicle context follows the linked content.
- The title-bar X minimizes Tome into its existing draggable launcher. Minimize and restore animations use the launcher's current position, including after moving it while Tome is parked. A small separate X closes Tome completely.
- Ordinary restore preserves the selected view, drafts, scroll and window rectangle. Reduced-motion preferences are respected. Background renders and hidden-window geometry writes are deferred while parked.
- Library and profile link-management stability fixes reduce layout jumps, preserve active controls and prevent redundant refresh loops.

## Supported scope and installation

The migration framework is system-neutral; system mechanics require verified adapters and GM review. **This release does not promise automatic conversion between every RPG system, and Genesys mechanical conversion remains future work.** Imported macros and unknown rules are preserved as source information rather than executed. Campaign migration is not a full Foundry server backup or a general automatic rollback system.

Runtime baseline: **Foundry VTT 13.351**. Compatibility metadata retains minimum 13 and maximum 14; direct V14 runtime verification remains a separate task.

Update the whole module, restart Foundry and hard-refresh the client. Existing campaign imports do not need to be repeated for the interface changes. Before migrating a campaign, retain normal Foundry backups and review the source/target preview.
