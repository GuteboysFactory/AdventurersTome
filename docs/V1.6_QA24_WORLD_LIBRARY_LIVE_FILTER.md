# Adventurer's Tome v1.6.0-qa.24 — World Library Live Filter

**Baseline:** v1.6.0-qa.23  
**Foundry target:** V13.351

## Goal

Add a local, zero-navigation search/filter directly to the World library.

This is not the global Tome Search page. It filters the World catalog in-place.

## Search surface

The World filter bar now contains:

- **Search World…**
- scope toggle:
  - **Current folder**
  - **All World**
- existing Import Journals control
- live result count

## Search coverage

World filtering searches visible World Journal data including:

- Journal name
- World profile subtitle
- summary
- body
- category
- structured facts
- Journal text-page names/content
- image captions
- folder path

Multiple search terms use AND matching.

Example:

`bree inn`

requires both terms to exist somewhere in the same World entry search text.

## Scope

### Current folder

Default.

Searches the currently selected Campaign Explorer folder and its nested folders.

### All World

Searches all World entries without changing the selected Campaign Explorer folder.

Clearing the query restores the normal folder filter.

## UX

- filtering occurs live while typing
- no page navigation
- X clears the query
- Escape clears the query while the search field is focused
- result count changes to e.g. `3 of 17 entries`
- category counts update to visible matches
- empty categories hide automatically
- search state survives normal Explorer remounts during the current Tome session
