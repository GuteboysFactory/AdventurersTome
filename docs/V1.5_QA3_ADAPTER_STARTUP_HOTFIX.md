# Adventurer's Tome v1.5.0-qa.3 — Adapter Startup Hotfix

**Scope:** startup lifecycle hotfix for the optional Genesys reference adapter.

## Observed defect

During Foundry ESModule startup, `world-system-adapter-genesys-registry.js` attempted:

```js
game.modules.get("adventurers-tome")
```

before `game.modules` existed.

Observed error:

```text
Uncaught TypeError: Cannot read properties of undefined (reading 'get')
```

## Root cause

The optional reference adapter is loaded as an ESModule and performs an early registration attempt. The formal Adapter API bridge already exists globally at that phase, but the registry lookup attempted the later Foundry module collection first.

This is a Tome startup timing defect, not a Genesys or Realm Guard defect.

## Fix

Registry lookup is now lifecycle-safe:

1. use `globalThis.AdventurersTomeSystemAdapters` when the early bridge is already available;
2. otherwise query the formal module API only when `globalThis.game?.modules?.get` exists;
3. return `null` safely if neither registry is available yet;
4. retain the existing `ready` retry path.

No Adapter API contract, action bridge, campaign data, or system-specific behavior changes.
