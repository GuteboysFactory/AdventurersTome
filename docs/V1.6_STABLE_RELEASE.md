## Architectural locks

- Foundry stores; Tome presents and authors.
- Core owns semantic infrastructure; systems own rule-specific creation.
- Viewer-scoped evidence is the privacy authority.
- Display name alone never establishes canonical identity.
- Native system creation is delegated through stable adapter/provider contracts.
