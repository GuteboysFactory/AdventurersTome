# Adventurer’s Tome 1.8.0

Adventurer’s Tome 1.8.0 adds **My Chronicle**, a player-facing campaign notebook that keeps each player’s notes separate from authoritative campaign knowledge.

Players can create private notes, choose to share a saved version with the GM or party, withdraw shared versions, and optionally protect encrypted notes with their own passphrase. Sharing is explicit; private notes do not become GM-visible campaign facts. Shared player thoughts remain signals for GM review and are not automatically converted into canon.

The release also adds player-scoped **Known to Me** and **Remembered Moments** views. These are derived only from notes visible to the current player. Notes can link to campaign entities using their canonical Foundry identities, with Chronicle access available from supported Tome entity views. The GM’s Next Session Dashboard can summarize explicitly shared Player Signals.

Player Chronicle data stays outside Campaign Index, Campaign Memory analysis, campaign discovery and GM-private facts. Existing Foundry documents remain authoritative for campaign content.

## Included work

- Player Chronicle foundation with private notes, bookmarks, editing, deletion and search.
- Explicit, versioned sharing with the GM or party, plus withdrawal of shared snapshots.
- Optional encrypted-note protection and recovery/passphrase controls.
- Player-scoped entity knowledge and dated remembered moments.
- GM-only Player Signals, clearly separated from confirmed campaign facts.
- Chronicle entity links across Actor, World, Session, Quest and generic entity details.
- Swedish and English language support and responsive Tome styling.

Verified on Foundry VTT 13.351. The release package is built and validated by the repository’s stable-release workflow.
