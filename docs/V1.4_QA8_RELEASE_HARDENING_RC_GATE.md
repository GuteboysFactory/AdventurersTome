# Adventurer's Tome v1.4.0-qa.8 — Release Hardening / RC Gate

**Foundry runtime baseline:** V13.351 verified  
**Architecture policy:** v14-first, v13-compatible; V14 runtime verification remains separate  
**Tome QA build:** v1.4.0-qa.8  
**Host policy:** system-independent; external hosts are optional capability providers, never Tome runtime dependencies.

## Goal

Close the v1.4 GM Dock QA line with a release-candidate gate. This package does not add campaign features. It verifies startup, API composition, canonical-source convergence, GM privacy, standalone behavior, generic host behavior, reload safety and console cleanliness.

## A. Runtime release gate

As GM, run:

```js
game.modules.get("adventurers-tome")?.api?.gmDock?.releaseGate?.()
```

Expected:

- `phase: "v1.4-release-hardening-rc-gate"`
- `version: "1.4.0-qa.8"`
- `healthy: true`
- every entry in `checks` is `true`

The gate is deliberately capability-driven. `integration.systemId` is diagnostic only and must not influence any check.

## B. Standalone gate
