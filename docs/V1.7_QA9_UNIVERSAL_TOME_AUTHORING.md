# v1.7.0-qa.9 — Universal Tome Authoring Convergence

**Baseline:** v1.7.0-qa.8  
**Foundry baseline:** V13.351  
**Scope:** unify Session, Quest, World and Rule authoring lifecycle and remove competing normal GM authoring controls

## Goals

1. One authoring lifecycle across Tome.
2. Autosave/save must never terminate a live editor session.
3. A live editor owns the render lock until the user deliberately exits it.
4. Session and Quest normal UX must be task-first, not generic Journal/Page-first.
5. World remains the reference implementation, not a special case.

## Session / Quest UX convergence

For GM:

- generic `Create` buttons from Authoring Foundation are removed from Sessions and Quests
- task-specific `New Session` / `New Quest` remain authoritative
- generic `Page` buttons are removed from Session / Quest detail toolbars
- extra Journal pages remain available through **Advanced Pages**
- Chronicle / Overview remain canonical JournalEntryPage text

Delegated non-GM editor behavior remains available through the generic authoring path.

## Editor lifecycle convergence

Shared lifecycle:

```text
user enters editor
→ acquire editor session
→ _atRichEditingCount++
→ _bulkUpdating = true
→ user writes
→ autosave/save may run repeatedly
→ Saved — keep writing
→ no full Tome render while editor is active
→ user deliberately exits
→ final save settles
→ _atRichEditingCount--
→ release render lock
→ one queued refresh may run
```

### Covered surfaces

- Session Chronicle
- Quest Overview
- additional Journal-backed Session/Quest text surfaces
- World rich-text surfaces through the existing editor bridge
- Rule editor overlays
