# Adventurer's Tome v1.6.0-qa.10 — Discovery Resolved Classification Hotfix

**Baseline:** v1.6.0-qa.9  
**Verified Foundry baseline:** V13.351

## Problem

Live creation/linking of new Realm Guard relationship NPCs triggered Campaign Discovery refreshes and exposed:

```text
ReferenceError: resolved is not defined
at upsertEntity (universal-campaign-discovery.js)
```

Reconciliation and Contact Projection then failed safely because Discovery could not complete its snapshot.

## Root cause

The qa.9 semantic-only refactor retained the `state: resolved ? ...` classification expression while accidentally removing the local `resolved` declaration from the new-entity branch of `upsertEntity()`.

## Fix

Restore:

```js
const resolved = Boolean(canonicalUuid && uuidIndex.has(canonicalUuid));
```

immediately before semantic-only classification.

No discovery contract, adapter contract, reconciliation scoring, Contact projection model, authority rule or permission rule changes.
