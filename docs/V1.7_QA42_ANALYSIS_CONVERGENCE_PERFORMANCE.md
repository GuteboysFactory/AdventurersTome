# qa.42 analysis convergence performance

Follow-up to the live profile of 940ece3: startup elapsed 45,595 ms,
9 mention syncs / 34,260.2 ms accumulated, 23 new entity scans / 9,398.2 ms,
candidate resolution 9 calls / 12,882.5 ms, source identity resolution
1,379 calls / 543.1 ms. Timings overlap; accumulated phase time is not
wall-clock startup time. The previous source lookup fix is effective;
the overall Foundry startup target is not yet verified.

## Changes

- Discovery, semantic mention discovery and new entity discovery emit their
  Updated signals only when actual result content or viewer scope changes.
  Generated timestamps and scan-summary counters cannot restart the pipeline.
  All requested scans still run and return fresh snapshots.
- Silent scans leave the last-notified content unchanged, so a later visible
  scan still notifies consumers about results they have not received.
- Duplicate resolution uses a fresh, detached projection of Discovery identity
  fields (name, UUID, kind, aliases), rather than cloning full profiles and
  provenance for every candidate. Snapshot-only providers remain supported.
- Fuzzy full-name comparison stops early when the minimum edit cost already
  exceeds the existing acceptance threshold. Exact-name, alias, type, source,
  canonical authority and ambiguity rules remain in place. Candidates are never
  omitted by this optimization.

This is a focused correction to the current pipeline, not a new index engine,
worker or scheduler. It does not disable scans, edits or permissions handling.

## Validation

Seven added regressions verify unchanged notifications, real same-size content
changes and viewer changes, detached/fresh identity fields, snapshot-free
duplicate lookup, equivalence of fuzzy acceptance decisions, source evidence
edits, silent/non-silent notification delivery, and convergence of the real
mention/new-entity/Memory hook chain. Actual Foundry-style page updates still
trigger Memory refresh after the unchanged pipeline has settled.

All nine regression suites: 372/372 PASS (365 prior plus seven added).
Syntax: 87 ES modules plus one vendor script PASS. Manifest/workflow/QA URLs
PASS; `git diff --check` PASS.

A single synthetic comparison with 1,419 unrelated Discovery entities and ten
candidate resolutions measured the previous code at 12,513.4 ms and the updated
code at 5,752.3 ms. Both linked all ten candidates to the same person. Full
snapshot copies fell from ten to zero. This comparison includes both the
identity projection and bounded fuzzy-name calculation; it does not establish
a Foundry startup duration. An earlier projection-only run did not show a
speed improvement, so projection alone is not the claimed performance fix.
