# Adventurer's Tome v1.5.0 — Formal Adapter API Stable Release

**Verified runtime baseline:** Foundry VTT V13.351  
**Architecture policy:** v14-first, v13-compatible; V14 runtime verification remains separate  
**Core policy:** system-independent; reference systems are optional integrations only.

## Stable milestone

v1.5.0 completes the Formal Adapter API milestone.

The release turns the previous internal enrichment bridge into a versioned, public, capability-driven integration surface that other game systems and modules can use without making Tome Core depend on them.

## Shipped scope

- public `game.modules.get("adventurers-tome").api.adapters`
- Adapter API contract id `adventurers-tome-adapter-api`
- API version 1
- registration / unregistration lifecycle
- deterministic priority ordering
- optional system, document-type and source-type affinity
- capability discovery through `supports()` and `matching()`
- safe execution through `execute()`
- backward-compatible enrichment bridge
- normalized `displayFields()`
- `mapActor()` and `mapItem()`
- safe action discovery through `actions()`
- namespaced action keys `adapterId:actionId`
- controlled execution through `invokeAction()`
- standalone and hosted GM Dock action presentation
- GM-only action filtering
- disabled/unknown action protection
- failure containment and runtime audit diagnostics
- startup lifecycle hardening for optional reference adapters

## System-independence guarantee

Realm Guard / Torchbearer and Genesys may be used as reference integrations, but no specific reference-system release is a Tome runtime dependency.

Tome Core remains fully functional without any adapter.
