# Adventurer’s Tome 2.1.9

Based on 2.1.9-qa.13. Verified with Foundry VTT 13.351.

- **Token Builder.** Choose from 100 illustrated frames and 22 animated effects, including Ghostly Light, Holy Aura and Death Shadow. Adjust animation strength, tint and decorate frames, or change the diameter from 60% to 140%. The diameter also changes the size of the artwork on saved tokens. GMs can save a default frame. Token Builder and Portrait Editor scroll while the action buttons stay visible.
- **Player artwork and character sheets.** Players who own their character can save artwork when the GM enables Foundry file uploads. Uploads are stored in a folder per account. Players can open their assigned character sheet from the map menu. Scene management remains in the GM menu. The storage drop label has stronger contrast in Realm Guard.
- **Home, maps and scenes.** At a Glance shows the latest session number. GMs can update the party location from Home. Scene image import applies scene defaults and uses the source image dimensions when no size is configured.
- **Quick Search and Campaign Review.** Quick Search includes linked rule-page text. Review skips the internal parts of Foundry document links. Use **Never ask about this again…** to record a campaign-wide decision with a reason. Review or reverse it under **Campaign Tools → Memory**.
- **Manual.** Open the question mark in Tome for searchable Swedish and English guides, tutorials and reference entries.

Update through **Foundry → Add-on Modules** or use the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json).
