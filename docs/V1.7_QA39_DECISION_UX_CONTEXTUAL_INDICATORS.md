# v1.7.0-qa.39 — Decision UX & Contextual Indicators

**Baseline:** v1.7.0-qa.38
**Foundry baseline:** V13.351

## Goal

Make Guided GM Decisions readable at a glance and move review work out of Session/Quest information pages.

## Product rule

> **Session / Quest = information. Campaign Tools → Analysis = decisions.**

## Decision cards

Guided candidates now use the full available width.

Each candidate card shows, when available:

- portrait / item image
- large identity name
- type / role / profile metadata
- context reason
- a large **This is the one** action
- clear **★ Tome recommends** state when applicable

Optional **More info** expands extra:

- Facts
- Relations
- Previous Campaign Memory mentions

GM should be able to identify the correct candidate without reading tiny metadata.

## Session / Quest indicators

The large inline Campaign Analysis panel is retired from Session and Quest pages.

Instead:

- Session gets a fourth GM-only stat tile: **GM review**
- Quest gets a fourth GM-only glance tile: **GM review**
- the number is the pending guided decision count for that exact source
- 0 remains visible as an all-clear state
- players never see the tile
- clicking the tile opens Campaign Tools → Analysis focused on that Session/Quest

## Focused Analysis

Opening Analysis from a Session/Quest indicator applies a source focus.

Expected:

- only pending decisions for that source are shown
- a clear Focused review banner appears
- **Show all decisions** removes the focus
- Overview remains global and is never source-filtered

## Inline Campaign Analysis retirement

The legacy Session/Quest Campaign Analysis preview provider no longer mounts its large panel.

Its underlying discovery / learning APIs remain available for campaign intelligence and existing workflows.

## Safety locks

qa.39 does not change:

- Foundry canonical UUID authority
- guided decision writes from qa.38
- no-auto-create policy
- recommendation thresholds
- source-scoped defer behavior
- Campaign Memory history
- player privacy
