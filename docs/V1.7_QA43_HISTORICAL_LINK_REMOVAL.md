# qa.43 — Remove mistaken historical source associations

Review candidate cards now expose **Manage previous session links**. A GM can select a specific source association, confirm its removal, and undo the action through the existing recent decision history.

The identity and source text are retained. Only the selected source/target pair is unlinked. The existing source suppression policy prevents automatic relinking and excludes that association from historical identity suggestions. Historical evidence is retained for audit rather than deleted. Removing historical evidence without a live link is supported; Undo does not invent a link in that case.

The implementation is generic and contains no campaign-specific names. Independent same-name identities remain independent candidates. No automatic merge is performed.

Regression coverage exercises reload, reanalysis, Undo, historical-only associations, failed writes, permission checks, changed-link Undo protection, and cancelling the confirmation dialog.
