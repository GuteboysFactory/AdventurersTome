# 2.1.0-qa.4 — läsbar källa i Quest-förhandsvisningar

Rättar rå UUID-kod i Quest Record och sammanfattningen högst upp. Förhandsvisningar visar nu länkens läsbara etikett, exempelvis ”Session source”. Själva Overview-sidans klickbara länk bevaras. Samma textformatering används också i list- och hemsidesförhandsvisningar.

## Testa

1. Ersätt modulens filer i testmiljön med QA.4 och ladda om Foundry.
2. Öppna Questen som redan skapats. Ingen ny Quest eller import behövs.
3. Kontrollera att Quest Record och rubrikens sammanfattning visar ”Source: Session source” utan UUID-kod.
4. Kontrollera att Session source i Overview fortfarande öppnar rätt sessionssida.

Inga sparade Quests eller sessionsdata skrivs om. Oetiketterade referenser visas neutralt som ”Linked entry”. Förhandsvisningen slår inte upp dolda dokument eller deras namn. Detta är en textvisningsrättning; Quest-flödet från QA.3 ingår som tidigare.

## Verifiering

Fem riktade tester: läsbara etiketter, neutrala referenser utan uppslagning, långa UUID:er före trunkering, bibehållen markup-rensning samt verkliga questDetailView och Handlebars-mallar för både Quest-rubriken och Quest Record. Originaltextens källänk kontrolleras oförändrad. Syntax- och paketkontroll tillkommer; se PACKAGE-VERIFICATION.json. Livekontroll av QA.4 återstår.
