# Adventurer's Tome 1.7.0

Stable release of the tested 1.7 development track for Foundry VTT. This release promotes the approved build without adding new runtime behavior.

## Campaign understanding and review

- Improved Swedish and English language handling through shared analysis and dedicated language packs, including narrative names, titles, grammatical forms, role attribution, negation and temporal context.
- Improved identity matching, source-scoped decisions, matching preferences and controls for pausing automatic matching of an identity.
- Decision history, source-link management and Undo for supported GM decisions.
- Source fact correction and permission-aware handling of private GM facts.
- Relationship evidence and review distinguish possible claims from confirmed relationships.
- Consistent expandable review cards, clearer typography and more readable evidence.
- Latest identity/name cleanup, including Swedish leading-word handling, from the approved QA build.

## Campaign Index and responsiveness

- Dedicated Campaign Index page with background analysis, progress, change checks, rebuild and pause controls.
- Persistent browser-local analysis reuse for the current world and GM, with updates when sources change.
- Background worker processing and reduced repeated discovery work improve startup and review responsiveness.
- Stale analysis is retried when source data changes during processing.
- Less disruptive UI refreshes and scroll/view preservation during background updates.
- Archived identities can be excluded from automatic matching while history remains available. Deleted documents retain historical markers, not usable links.

## Installation

Stable installation manifest:
https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json

The release includes `module.json` and `adventurers-tome.zip`. Foundry compatibility metadata remains unchanged: minimum 13, verified 13.351, maximum 14.

The first analysis after a relevant cache update can take longer than subsequent loads. The Campaign Index is a local cache, not a replacement for Foundry documents or a backup. Ambiguous names and unsupported claims can still require a GM decision.
