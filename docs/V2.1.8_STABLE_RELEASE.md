# Adventurer’s Tome 2.1.8

Built from the approved 2.1.7-qa.22 with the addition of outward frame thickness in Token Builder.

- **Scene navigation and import.** Open the Scenes panel from the map’s context menu or GM Dock. Search and preview scenes, manage navigation settings, and create scenes from image files or the **Create scene here** drop target.
- **Scene defaults.** Set grid, dimensions, background color, vision, and lighting defaults for new scenes. Review and apply only the chosen fields to all or selected existing scenes. Individual scenes remain editable in Foundry.
- **Map and party travel.** Link multiple scenes to a marker. On arrival the GM can preview a linked scene or activate it for the table after confirmation. The group flag stays above map markers and tokens during movement.
- **Chat.** Show character names and token portraits for player messages. GM-controlled NPC names respect what each player knows. **Speak as** lets users search eligible characters, and the GM starts as Gamemaster.
- **Shared storage.** Move item stacks between character inventories and pack animals, chests, crates, or base storage. Foundry permissions control who can read or move items.
- **Token Builder.** Adjust inner and outer frame thickness independently. The outward control preserves the image crop and works for static and animated tokens. Choose artwork individually in Group and on the character sheet. Home uses the portrait with full artwork as a fallback, and the Foundry Actors list shows token artwork.

Update from Foundry’s **Add-on Modules** screen or use the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json). The release targets Foundry 13.351.
