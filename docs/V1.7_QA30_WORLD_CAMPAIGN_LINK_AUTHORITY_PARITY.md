# v1.7.0-qa.30 — World Campaign Link Authority Parity

**Baseline:** v1.7.0-qa.29  
**Foundry baseline:** V13.351  
**Scope:** make World Detail obey the same canonical-link authority boundary already established for Session and Quest detail views.

## Problem

World Detail previously populated **Campaign Links** from a mixed predicate:

- explicit / canonical Campaign Link
- reciprocal legacy link
- text mention in Session, Quest or Actor prose

That meant a World entry such as `Pale Wardens` could display:

```text
Campaign Links
Sessions
- Session 1 — QA test Session 1
```

while the Session itself correctly displayed:

```text
0 WORLD LINKS
```

The World page therefore made a heuristic mention look authoritative.

## Locked rule

**Campaign Links means canonical/explicit links only.**

Heuristic text evidence is advisory and must render separately as **Tome noticed**.

This matches the authority split introduced for Session/Quest detail in qa.24.

## Canonical World-detail relationships

World Detail now treats these as canonical:

### Sessions

- target World Journal has an explicit reciprocal Session link; or
- Session has an explicit/canonical World link to the current World Journal

### Quests

- target World Journal has an explicit reciprocal Quest link; or
- Quest has an explicit/canonical World link to the current World Journal

### Characters

- target World Journal has an explicit Actor link; or
- Actor has an explicit World link to the current World Journal

No prose-only match is included in these arrays.

## Tome noticed

The existing heuristic evidence is preserved, but rendered as read-only suggestions:

- World entry name mentioned in Session text
- Session referenced in World entry text
- World entry name mentioned in Quest text
- World entry name mentioned in Actor profile

Suggested rows continue through the shared identity reconciliation presentation before rendering.

## QA fixture

Use the clean-world Session:

`Session 1 — QA test Session 1`

with prose mentioning `Pale Wardens`.

### A — before canonical link

Expected on Session:

```text
WORLD LINKS: 0
Tome noticed: Pale Wardens
```

Expected on Pale Wardens World Detail:

```text
Campaign Links
No canonical Campaign Links yet.

Tome noticed
Session 1 — QA test Session 1
Text mention only
```

The Session must **not** appear under World Detail Campaign Links merely because the prose contains `Pale Wardens`.

### B — after explicit Link Existing

Create a real canonical Session → Pale Wardens Campaign Link.

Expected on Session:

```text
WORLD LINKS: 1
Pale Wardens
```

Expected on Pale Wardens:

```text
Campaign Links
Sessions
Session 1 — QA test Session 1
```

The same relationship must be authoritative from both directions.

### C — source-scoped resolution follow-up

With the canonical link present, Campaign Analysis for the mention `Pale Wardens` should consume that source-local evidence and no longer remain merely unresolved.

This is the qa.27 source-scoped authority retest after World UI authority parity is corrected.

## Safety

- no automatic Campaign Link writes
- no auto-create
- no document merge
- no confidence-driven writes
- existing GM-explicit graph-write boundary remains unchanged
- qa.29 Foundry backend/source-of-truth behavior remains unchanged

## PASS gate

qa.30 passes when World Detail Campaign Links contains only explicit/canonical relationships, heuristic relationships appear only under Tome noticed, and an explicit link produces the same authoritative relationship on both Session/Quest and World Detail surfaces.
