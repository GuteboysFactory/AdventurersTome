# v1.7.0-qa.18 — GM Review & Campaign Learning Foundation

**Baseline:** v1.7.0-qa.17  
**Foundry baseline:** V13.351  
**Scope:** let the GM review Campaign Intelligence candidates and persist explicit per-campaign learning without creating entities or writing Campaign Links.

## Goal

Turn Campaign Analysis from read-only inspection into a controlled GM feedback loop:

```text
Tome detects
→ GM reviews
→ explicit feedback is stored
→ future scans use that feedback
```

No automatic self-training is introduced.

## Review actions

### Confirm

Marks a candidate as a real campaign entity candidate.

- stored per world/campaign
- preserves the detected semantic type
- does not create an Actor, Journal, Item or other Foundry Document
- does not create a Campaign Link

### Ignore once

Suppresses that candidate only for the current Session / Quest source.

Useful when the same word may be meaningful elsewhere in the campaign.

### Suppress

Stores a campaign-wide rejection for that normalized candidate name.

Future Session / Quest scans suppress the same name in this campaign until the decision is cleared.

### Link existing

Stores an explicit GM mapping:

```text
candidate text
→ existing viewer-visible canonical campaign entity
```

Example:

```text
Pale Warden
→ Pale Wardens
```

This is campaign learning only. It does not write the normal Tome Campaign Link structure in qa.18.

## Storage

World-scoped hidden Foundry setting:

```text
adventurers-tome.campaignIntelligenceLearning
```

The setting stores only explicit GM decisions:

- confirmed candidates
- campaign suppressions
- source-local ignores
- links to existing canonical UUIDs

No campaign prose is copied into the learning store.

## Public API

```js
const l = game.modules
  .get("adventurers-tome")
  .api.campaignReviewLearning;
```

Available:

```js
l.decisionFor(text, { sourceUuid })
l.confirm({ text, kind, sourceUuid })
l.ignoreOnce({ text, sourceUuid })
l.suppress({ text })
l.linkExisting({ text, sourceUuid, targetUuid })
l.clear({ text, sourceUuid, scope })
l.linkTargets()
l.all()
l.summary()
l.audit()
```

## Campaign Analysis UI

Possible-new-entity cards now expose:

- Confirm
- Ignore once
- Suppress
- Link existing

Confirmed / linked decisions are shown as learned state.

Ignored / suppressed candidates disappear from the normal Possible New list after the next scan.

## Audit

```js
l.audit()
```

Expected:

- `healthy = true`
- `gmOnlyWrites = true`
- `storageScope = "world"`
- `explicitFeedbackOnly = true`
- `autoLearning = false`
- `entityCreation = false`
- `campaignLinkWrites = false`

## Safety

qa.18 MUST NOT:

- create Foundry entities
- modify Session / Quest prose
- auto-create aliases
- write normal Campaign Links
- infer a GM decision from model confidence
- learn from its own prior guesses without explicit GM action

## PASS gate

qa.18 passes when explicit GM review decisions persist per campaign, future scans respect Ignore/Suppress, Confirm/Link states survive reload, and no canonical campaign data is created or linked automatically.
