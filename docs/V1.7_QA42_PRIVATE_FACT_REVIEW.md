# qa.42 — Review private source facts

The World view combines shared profile facts with the current GM's private vault facts. Source correction previously inspected only the shared profile, leaving migrated role and excerpt fields out of the correction dialog.

The correction planner now reads both stores through Tome's existing private vault accessors. Private rows are labelled in the dialog. Selected changes are written back to their original store; private notes, relationships and unchecked facts are preserved. No campaign names, game-system identifiers or special-case entity IDs are used.

New correction undo snapshots are stored in a user-scoped setting. Shared decision history contains only a reference to the snapshot. Only the GM who made the correction can undo it. Existing legacy profile-only history remains supported. Undo checks for later changes in the affected stores and refuses stale restoration. Failed saves attempt to restore the prior state in both stores.

The change extends the existing correction rules; it does not claim unrestricted natural-language understanding or automatically merge identities. No index service, startup scan, version bump or publication is included.

## Validation

Regression coverage uses Tome's actual private vault accessors with per-user settings. It checks English and Swedish fixtures with unrelated names, mixed shared/private fields, reload and Undo, private-only writes, GM/player isolation, stale changes, handwritten notes, and rollback after storage/history failures. Existing source-review and decision-history coverage is retained.
