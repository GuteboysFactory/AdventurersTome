# Adventurer's Tome v1.6.0-qa.19 — Quick NPC UI

**Baseline:** v1.6.0-qa.18 FULL PASS  
**Foundry target:** V13.351  
**Scope:** First usable UI on top of the verified System-aware NPC Creation Contract

## Goal

Expose Quick NPC to the GM without allowing UI code to write system-specific Actor paths directly.

The UI must remain a thin client of:

- `api.npcCreation.schema()`
- `api.npcCreation.plan()`
- `api.npcCreation.apply()`

## New public API

```js
game.modules.get("adventurers-tome").api.quickNpc
```

Methods:

- `open(options)`
- `audit()`

## Workflow

```text
Quick NPC
   ↓
dynamic form from npcCreation.schema()
   ↓
Preview Plan
   ↓
creation contract duplicate scan
   ├─ reuse exact World Actor
   ├─ import exact Compendium Actor
   ├─ create new Actor
   └─ ambiguous duplicate → choose canonical candidate
   ↓
explicit Apply
   ↓
Actor sheet opens
```

## Safety

- GM-only
- no direct UI writes to `actor.system`
- no create before plan preview
- no implicit apply
- blocked ambiguous duplicates require explicit candidate choice
- schema validation errors stay inside the workflow
- creation contract remains the only mutation authority

## QA

### A. Open UI

As GM, either:

- open **World** and click **Quick NPC**, or
- call:

```js
game.modules.get("adventurers-tome").api.quickNpc.open()
```

Expected:

- Quick NPC button is visible to GM on the World page
- Quick NPC dialog opens
- fields come from the active Realm Guard adapter schema
- Name plus Concept / Rank / Homeland / Ancestry / Biography / Notes
- no Actor created yet

### B. Create new

Use a unique name, for example:

`Tome UI QA NPC 19`

Preview.

Expected:

- review step says **Create New NPC**
- no Actor exists before Apply

Apply.

Expected:

- exactly one NPC Actor is created
- its sheet opens
- data matches the entered values
- provenance remains from the qa.18 creation contract

### C. Reuse duplicate

Open Quick NPC again with exactly the same name.

Expected:

- review step says **Use Existing World Actor**
- Apply reuses the existing Actor
- no duplicate Actor is created

### D. Back / edit

From review, press Back.

Expected:

- entered values are preserved
- editing and re-preview works
- still no mutation until Apply

### E. Cancel

Cancel from form or review.

Expected:

- no mutation

### F. Player safety

As non-GM:

```js
game.modules.get("adventurers-tome").api.quickNpc.open()
```

Expected:

- blocked with GM-only warning
- no dialog
- no Actor created

### G. Audit

```js
game.modules.get("adventurers-tome").api.quickNpc.audit()
```

Expected:

- `healthy:true`
- `gmOnly:true`
- `npcCreationContract:true`

Then run the full v1.6 regression audit including both `npcCreation` and `quickNpc`.

## Promotion rule

qa.19 passes when UI creation, duplicate reuse, back/edit, cancel, player block, and the full prior regression all pass.
