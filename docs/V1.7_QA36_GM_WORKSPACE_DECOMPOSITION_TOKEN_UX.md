# v1.7.0-qa.36 — GM Workspace Decomposition & Token UX

**Baseline:** v1.7.0-qa.35  
**Foundry baseline:** V13.351

## Goal

Finish decomposing the old monolithic GM Notebook / Workspace and move the useful surfaces into the new Campaign Tools information architecture, while adding two token-level GM/player UX improvements requested during live QA.

## Locked UX rule

> **Header = global utilities. Campaign Tools = GM workflows. Token HUD = token-context actions.**

## Campaign Tools changes

### Overview

**Notebook Overview** now lives directly under **Campaign Tools → Overview**.

It exposes the existing private GM note summary:

- Open
- Pinned
- Due
- Secrets
- Reveals
- Resolved
- compact preview of the newest open GM notes

This reuses the existing GM Notebook data model. No parallel data store is introduced.

### Assistant

**Campaign Scratchpad** now lives directly under **Campaign Tools → Assistant**.

**Custom Notepads** also live directly under Assistant.

The existing private GM workspace storage is reused unchanged:

- scratchpad
- custom pads
- structured notes

The legacy GM Notebook Settings page is no longer exposed in Campaign Settings navigation.

Existing openNotebook entry points now route to **Campaign Tools → Assistant** and scroll toward the Scratchpad.

## Private Vault — Token HUD

A GM-only **Private Vault** action is added to the Foundry Token HUD.

Expected behavior:

- only GM sees the Vault token action
- the action resolves the token's canonical Actor
- Tome opens that Actor's profile editor in explicit **Private Vault** mode
- the view explains that GM-only Facts and Relations are private
- GM Note remains available from the Vault banner
- player-visible and GM-only profile data remain separated by the existing profile save logic
- no new token/Actor data authority is introduced

## Token name on hover

Token hover temporarily reveals the token/Actor nameplate without persisting any token-document setting.

Privacy rule:

- GM may see the hover name
- non-GM users only get the hover name if they have Observer-or-better permission to the Actor
- hidden/unauthorized Actor names must not be exposed
- leaving hover restores the previous nameplate visibility/renderability state

## Authority / privacy locks

qa.36 does not change:

- Foundry Document backend/source of truth
- canonical UUID authority
- Campaign Link semantics
- Mention evidence semantics
- deterministic auto-link rules
- ambiguity handling
- auto-create policy
- player permission boundaries
- private GM workspace storage model

## QA

### A — Campaign Tools Overview

Open **Campaign Tools → Overview**.

Expected:
- Notebook Overview is present
- Open / Pinned / Due / Secrets / Reveals / Resolved counters render
- up to six current open-note previews may render
- source-linked notes can still jump to their source

### B — Assistant Scratchpad

Open **Campaign Tools → Assistant**.

Expected:
- Campaign Scratchpad is directly visible
- text can be edited and saved
- reload preserves the saved scratchpad
- scratchpad remains GM-private

### C — Custom Notepads

In Assistant:

Expected:
- Add Notepad creates a private pad
- title/body can be edited and saved
- delete works with confirmation
- reload preserves pads
- no player exposure

### D — Legacy GM Notebook routing

Trigger any existing openNotebook action, for example from Next Session Dashboard.

Expected:
- it routes to Campaign Tools → Assistant
- it no longer opens the old GM Notebook Settings page
- Scratchpad is brought into view

### E — Token Private Vault

As GM, select a token and open its Token HUD.

Expected:
- a Private Vault control is present
- clicking it opens Tome on the correct Actor
- profile editor enters explicit Private Vault mode
- banner identifies the Actor
- GM Note action works
- Facts / Relations can still be marked GM only

### F — Token hover name

Hover a token.

Expected:
- readable token/Actor name appears while hovered
- leaving restores the previous nameplate state
- no Token Document display-name setting is modified

Repeat as player:

Expected:
- owned/observable Actor name may appear
- Actor names without Observer permission do not become visible

### G — Player privacy

As player:

Expected:
- Campaign Tools remains absent
- Scratchpad and Custom Notepads are absent
- Notebook Overview private counts/notes are absent
- Token Private Vault action is absent
- no private facts/relations/GM notes leak
