# v1.7.0-qa.28 — Source-Scoped API Binding Hotfix

**Baseline:** v1.7.0-qa.27  
**Foundry baseline:** V13.351  
**Scope:** fix a render-time ReferenceError introduced in qa.27.

## Failure

Session detail rendering could fail with:

```text
ReferenceError: sourceScopedApi is not defined
at reconcileSuggestedCollections(...)
at sessionDetailView(...)
```

qa.27 referenced the Source-Scoped Identity API inside `reconcileSuggestedCollections()` without binding the local variable.

## Fix

The function now binds:

```js
const sourceScopedApi =
  game.modules.get(MODULE_ID)?.api?.campaignSourceScopedIdentity || null;
```

No qa.27 resolution logic changes.
