# Adventurer’s Tome 2.1.11

Based on 2.1.11-qa.3 with Token Builder verified in Foundry VTT 13.351.

- Frame effects can extend past the token’s grid footprint, including with **Fit to token edges**. The token keeps its grid size.
- The square token outline stays hidden when hovering, selecting, or dragging a token.
- Token Builder has a visible scrollbar on the right. **Save token** and **Cancel** remain in view while scrolling.

For an older animated token, open **Token Builder** and click **Save token** to regenerate its video with the current settings.

Update through **Foundry → Add-on Modules** or use the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json).
