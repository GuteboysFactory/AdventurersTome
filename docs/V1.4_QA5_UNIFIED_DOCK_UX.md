# Adventurer's Tome v1.4.0-qa.5 — Unified Dock UX & Universal Context QA

**Reference host:** any compatible `gbf-gm-dock-host` implementation; Realm Guard / Torchbearer was used as one live reference only

## Goal

Verify the polished unified GM Dock experience after the host/provider architecture proved stable.

## 1. Single Dock / host v2

- [ ] With any compatible host active, only one GM Dock is visible.
- [ ] Tome appears as an integrated provider in that host Dock.
- [ ] Tome does not render its standalone Dock while hosted.
- [ ] Host-owned tools still work unchanged.

## 2. Compact hosted menu

- [ ] Tome menu opens without layout jump or render loop.
- [ ] Header shows current canonical context.
- [ ] Recent section shows at most 3 direct recent entries.
- [ ] If more recents exist, a compact “More recent entries” action appears.
- [ ] Open Adventurer's Tome remains visible as a dedicated footer action.

## 3. Hosted Quick Capture

- [ ] Quick Capture form is visible directly inside the hosted Tome menu.
- [ ] Saving to Current Context works for Actor/Journal/Scene/Item where a stable UUID exists.
- [ ] Saving to GM Quick Capture Inbox still works.
- [ ] Empty title + body is rejected.
- [ ] Successful save clears the form and refreshes badge/context counts.
- [ ] Capture does not create a parallel campaign data model.

## 4. Universal contextual Private Vault

- [ ] Actor context opens the existing UUID-backed Private Vault.
- [ ] Journal context opens the existing UUID-backed Private Vault.
- [ ] Scene context opens a Private Vault record without requiring a Tome ref.
- [ ] Item context opens a Private Vault record without requiring a Tome ref.
- [ ] Note count badge updates from the same contextual Vault.
- [ ] Rename/reload preserves UUID identity.
- [ ] Player client never receives GM-private content.

## 5. Standalone fallback

In a world without a compatible GM Dock Host:

- [ ] Tome still renders its own Dock.
- [ ] Standalone Quick Capture can save to current canonical context.
- [ ] Standalone Private Vault works for canonical Foundry documents.
- [ ] Position persistence remains per-user.
