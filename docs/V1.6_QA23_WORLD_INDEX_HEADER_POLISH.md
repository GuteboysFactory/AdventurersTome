# Adventurer's Tome v1.6.0-qa.23 — World Index Header Polish

**Baseline:** v1.6.0-qa.22  
**Foundry target:** V13.351

## Goal

Reduce visual clutter in the World index now that Quick Create lives on semantic folders.

## Changes

- remove the redundant World-header Quick NPC shortcut
- collapse the legacy "Already have campaign Journals?" helper block
- preserve the existing Import Existing Journals action
- expose that import action as a compact **Import Journals** control in the catalog/filter bar, next to the entry count
- keep Create and Editors as the only persistent header actions
- retain all existing import behavior by proxying the original functional import control rather than introducing a new import implementation
- add responsive layout for narrow Tome windows

## QA

### A. Header

Open Tome -> World as GM.

Expected:

- title/copy remain on the left
- no Quick NPC button in the World header
- no "Already have campaign Journals?" helper block
- Create and Editors remain visible and aligned cleanly on the right

### B. Import placement

Select any World folder.

Expected:

- **Import Journals** appears on the right side of the folder filter bar
- entry count remains directly below/next to it
- clicking Import Journals opens the same existing import workflow as before

### C. Quick Create regression

Right-click NPC / Contacts / Factions / Items / Locations / Lore.

Expected:

- qa.22 context menus still work
- native Realm Guard NPC/NPC Group delegation remains unchanged

### D. Narrow layout

Reduce the Tome window width.

Expected:

- header actions wrap below the World title
- filter-bar import/count remain readable without overlap
