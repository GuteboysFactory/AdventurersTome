# 1.9.0-qa.4 — Shared Import & Export

Local QA delivery; stable channel remains 1.8.0. Actual TAF campaign verification is still pending and this build is not published.

## One workspace

Campaign Settings → Developer Tools now has one Import & Export card. Existing Import Session / Import Quest shortcuts route to this same workspace with the relevant log type. The legacy migration API remains a GM-only compatibility entry point; `api.transfer.open()` provides the role-aware shared workspace.

GM Import recognizes campaign ZIPs, older Tome JSON packages, Markdown and text. Paste is available under the source panel. ZIPs retain copy-only migration, account mapping, private-data transfer, compendium handling and retry. Content imports use the existing reviewed Create / Update / Skip and explicit cross-link engine, preserving its permissions and latest-transaction Undo behavior. Import history, Clear History and confirmed Undo remain available in this workspace.

GM Export offers campaign ZIP, portable Tome JSON, player-safe JSON and private GM archive. Clipboard export is retained for the JSON variants. Older GM archives remain reference/backup files; they are not silently treated as full restorable world packages. Use campaign ZIP for world/system migration. Player-safe export preserves the existing discovered/default-ownership filters and warning about stricter user-specific permissions.

Players open Import & Export from My Chronicle. Their shared window contains only their own Chronicle import/export, without evaluating campaign inventory or GM history. Cross-world imports need their mapped account's GM-authored addressed receipt. Same-account, same-world backups can be restored directly. Notes remain outside Campaign Index; optional encryption and original authentication context are preserved. Export never includes the player's inbox or receipt store.

## Hardening

- Content previews are privately snapshotted; UI mutation cannot forge a transaction. A consumed preview cannot be applied twice.
- Changed campaign data, edited source text or changed log type requires another preview. Invalid Update and unresolved link application are rejected before writes.
- Content import can stop between documents. Saved partial changes retain the native Undo transaction; captured snapshots remain available even after an update fails. Cancellation before import creates no folders.
- Migration retains the existing 800-document stress cases, immutable mapping plans, staged GM-only copies, standard-folder aliases, saved-copy retry, private-restoration checkpoints and addressed receipts.
- No automatic rollback of campaign migration or deletion of previously edited target copies. Saved copies remain and are reused on retry; the source world stays intact. Content Undo is explicitly limited to its latest transaction.

2. Export each appropriate format. Load an existing qa.3 campaign ZIP in the shared Import tab and verify mapping/copy flow.

Automated system-neutral adapter fixtures are contract tests, not a production converter for every game's mechanics. Unsupported rules data is preserved and reported instead of guessed. TAF live testing is still required before deciding on stable 1.9.0.
