# Adventurer’s Tome 2.1.10

Based on 2.1.10-qa.2 and verified with Foundry VTT 13.351.

- **Import scenes from images.** Drop one or more images into Foundry’s Scenes sidebar, use the Tome file picker, or drop them onto **Create scene here** on the canvas. Each image supplies the scene name and background. Realm Guard’s NPC image drop still uses the rest of the canvas.
- **Import settings.** Choose an upload folder, visibility in navigation, player access and whether to activate the last successful import. **Fog exploration** is available in scene defaults. The sidebar drop area can be hidden.
- **Existing files and scenes.** Create a separate copy, skip, reuse the existing image or replace it after confirmation. Updates preserve an existing scene’s navigation and player access and refresh its thumbnail when the canvas is available.
- **Scene controls.** **Compact scenes** and **Scenes** start at the top of the map. Drag their handle to move them or right-click it to reset the saved position.

Update through **Foundry → Add-on Modules** or use the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json).
