# Adventurer's Tome v1.5.0-qa.1 — Formal Adapter API Foundation

**Stable baseline:** v1.4.0  
**Verified Foundry baseline:** V13.351  
**Core policy:** system-agnostic; adapters are optional capability providers.

## Goal

Formalize the previously internal/experimental system-adapter layer into a stable public API without making any specific game system a Core dependency.

## Public API

Preferred access:

```js
game.modules.get("adventurers-tome")?.api?.adapters
```

Expected contract:

```js
{
  contract: "adventurers-tome-adapter-api",
  version: 1,
  capabilities: [
    "enrich",
    "actorMapping",
    "itemMapping",
    "displayFields",
    "npcSchema",
    "actions",
    "rules",
    "presentation"
  ],
  register,
  unregister,
  get,
  list,
  matching,
  supports,
  execute,
  enrich,
  audit
}
```

The legacy global bridge remains temporarily available for compatibility:

```js
globalThis.AdventurersTomeSystemAdapters
```

New integrations should use the module API.

## Adapter contract

A v1 adapter may declare:

- `id` — required stable identifier
- `label`
- `apiVersion: 1`
- `systemId` — optional system affinity
- `priority`
- `documentTypes`
- `sourceTypes`
- `capabilities`
- `matches({ source, systemId, game })`
- one or more capability handlers

Core never imports a system package directly.

## QA A — API surface

```js
const a = game.modules.get("adventurers-tome")?.api?.adapters;

  matching: typeof a?.matching,

  audit: typeof a?.audit

```

Expected:
- contract = `adventurers-tome-adapter-api`
- version = `1`
- every function field = `"function"`

## QA B — no-adapter / unrelated-system baseline

In any world where no matching adapter is active:

- [ ] Tome starts normally
- [ ] `api.adapters.audit().healthy === true`
- [ ] `api.adapters.supports("enrich", source)` safely returns false when nothing matches
- [ ] World/Quick Import remains functional without adapter enrichment
- [ ] no system-specific API is required by Tome Core

## QA C — registration lifecycle

Register a temporary test adapter:

```js
const a = game.modules.get("adventurers-tome").api.adapters;
a.register({
  id: "qa-test-adapter",
  apiVersion: 1,
  priority: 999,
  capabilities: ["enrich"],
  matches: () => true,
  enrich: () => ({ summary: "QA adapter active", bodyHtml: "", facts: [] })
});
```

Verify:
- [ ] `a.list().includes("qa-test-adapter")`
- [ ] duplicate registration without replace throws safely
- [ ] `a.unregister("qa-test-adapter") === true`
- [ ] adapter disappears from list after unregister

## QA D — capability execution

For a temporary adapter:
- [ ] `matching(source, "enrich")` only returns compatible adapters
- [ ] priority ordering is deterministic
- [ ] adapter exceptions are contained and reported in audit stats
- [ ] one failed adapter does not prevent later adapters from executing

## QA E — Genesys reference adapter

When Genesys VTT is the active system and the optional Genesys registry adapter can resolve a Talent:

- [ ] no Genesys class/import exists in Tome Core

- [ ] the adapter may remain registered as metadata, but does not match unrelated sources
- [ ] Tome Core behavior is unchanged
