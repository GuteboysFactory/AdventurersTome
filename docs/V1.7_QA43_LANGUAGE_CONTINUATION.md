# Language continuation after the index foundation

Local QA package, not a published release. Includes the campaign index foundation.

Swedish and English role evidence now understands explicit historical auxiliary
predicates: `har tidigare varit`, `hade arbetat som`, `brukade vara`, `has previously
been`, `had served as` and `used to work as`. Ongoing `för närvarande` and
`is currently working as` are recognized as current roles. Relative clauses and
immediately coordinated predicates use the same rules. A new named subject never
inherits the previous person's role; existing conservative pronoun attribution
and uncertainty gates continue to apply.

Bare `har varit` / `has been` still abstain because these formulations alone do
not determine current versus historical status. Negation, questions, rumours and
unrelated verbs do not become positive role facts. Historical means evidence
about a past role, not proof the person cannot hold that role today.

Index analysis revision advances to `qa43-index-language-2`. Previously derived
answers and source signatures are invalidated, while local history and paused
queue state are retained. Existing canonical documents, source choices and
matching preferences are not rewritten. Expect one background reanalysis after
installation, followed by reuse on unchanged reloads. A paused index must be
resumed to refresh its sources.

Session 8 remains a regression fixture: the late unspecified Karin reference is
genuinely ambiguous and must stay reviewable. An unknown destination such as Åsby
can be classified as a location without assuming that a new canonical place has
already been approved. This patch does not aim for a zero-length Review queue.

Validation covers temporal predicates in both languages, refusals, coordination,
subject attribution, existing Session 8 behavior, and real browser worker/cache
equivalence. The browser test also upgrades a saved old revision and verifies that
analysis is recomputed while a deleted NPC marker and paused state survive.
