# 1.9.0-qa.2.4 — Campaign data and system complements

Realm Guard's eight canonical starter packs are system complements even though the system seeds them into world compendium storage. They include the Quick NPC library, skills, traits, wises, conditions, gear, tokens of power and talents. They are excluded from the export selector and from export payloads, without loading their document data. Native system-owned packs are excluded as well. The excluded libraries remain visible as an explanatory list in Export.

Import filters these libraries from older ZIPs too. The supplied 815-document test ZIP now selects 143 campaign documents and excludes 672 system-library entries (435 NPC templates plus 237 Item templates). Active world NPCs are retained even when they carry starter/template flags. Earlier erroneous world copies are recognized by their migration provenance and excluded from re-export; they are not deleted automatically.

GM-created compendiums are still exportable. Import stores them in separate private world packs with a migrated label, rather than instantiating the contents as world Actors/Items. Existing installed packs are not overwritten. Folder IDs are scoped by pack, NPC/Character types are preserved, embedded IDs and links are remapped, and retry loads previously saved pack records. If pack creation is unavailable, the import fails before writing world templates.

The library exclusion applies to the canonical system libraries, including changes made inside those libraries. Keep campaign-specific templates in a separate GM pack or as active world documents if they should migrate.

Install QA.2.4 and test in a clean destination. The existing migration ZIP may be reused. In the import summary the old ZIP should report 672 system-library entries excluded and 143 campaign documents ready. Earlier wrongly imported templates in the destination are not automatically removed. Stable 1.8.0 and the remaining qa.3 private-storage/ownership scope are unchanged.

Automated coverage includes the original ZIP's filtered import, library read exclusion, retention of starter-based active NPCs, custom pack storage, private pack configuration, folder scoping, native API routing and retry. Browser document storage is simulated; live Foundry remains the final validation.

Implementation reference: [Foundry 13 CompendiumCollection](https://foundryvtt.com/api/v13/classes/foundry.documents.collections.CompendiumCollection.html).
