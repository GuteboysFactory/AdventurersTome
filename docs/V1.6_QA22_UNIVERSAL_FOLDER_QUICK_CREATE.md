# Adventurer's Tome v1.6.0-qa.22 — Universal Folder Quick Create + Standard Bootstrap

**Baseline:** v1.6.0-qa.21  
**Foundry target:** V13.351

## Goal

Turn Tome's Campaign Explorer folders into creation surfaces.

Right-clicking a semantic World folder exposes Quick Create. Tome delegates to a native system provider where one exists and otherwise uses Tome-owned generic templates.

## Core standard folders

On GM world ready, Tome non-destructively ensures:

- NPC
- NPC Groups
- Contacts
- Factions
- Items
- Locations
- Lore

The bootstrap also ensures the root structure:

- Adventurer's Tome
  - Sessions
  - Quests
  - World
  - Rules

Existing matching folders are adopted instead of duplicated. Tome marks adopted/created standard folders with stable semantic flags so later renames do not break their meaning.

Tome never deletes, moves or renames existing campaign folders during bootstrap.

## Provider expansion

The Adapter API adds:

- `quickCreateFolders`
- `quickCreate`

This lets a system add semantic categories such as:

- Spells
- Creatures / Monsters
- Organizations
- Deities / Religions
- Encounters
- Vehicles / Mounts
- Conditions / Effects
- Classes / Careers / Archetypes
- Talents / Feats / Abilities

These are not Core defaults. They are created only when a compatible system provider declares them.

## Quick Create routing

```text
Explorer folder right-click
      ↓
semantic folder type
      ↓
Quick Create router
      ├─ native system provider
      ├─ Tome generic templates
      └─ blank creation
```

### Realm Guard

- NPC -> Realm Guard native Quick NPC Library
- NPC Groups -> Realm Guard native Group Templates
- other Core types -> Tome generic template library unless Realm Guard later supplies a dedicated provider

## Generic Tome template libraries

qa.22 includes starting templates for:

- Contacts
- Factions
- Items
- Locations
- Lore
- NPC Groups fallback

Templates are starting points only. The created World entry is a normal editable Foundry Journal/Tome World profile.

Expected under **Adventurer's Tome -> World**:

- NPC or an adopted existing NPC/NPCs folder
- NPC Groups
- Contacts
- Factions
- Items
- Locations
- Lore

No duplicate matching folders.

### B. Rename safety

Rename one standard folder, reload.

Expected:

- Tome does not recreate the old name
- semantic behavior remains attached to the renamed folder

### C. Native NPC

Right-click NPC in Tome Campaign Explorer.

Expected menu:

- Quick Create NPC...

Select it.

Expected:

- Realm Guard Quick NPC Library opens
- native template search/filter UI remains unchanged

### D. Native NPC Groups

Right-click NPC Groups -> Quick Create NPC Group...

Expected:

- Realm Guard Group Templates opens

### E. Generic template categories

Test Contacts, Factions, Items, Locations and Lore.

Expected:

- right-click menu appears
- Quick Create opens a searchable template library
- selecting a template opens a small customization form
- created entry is placed in the selected folder
- Tome opens the new World profile for editing

### F. Nested folder inheritance

Create a subfolder under Locations and right-click it.

Expected:

- it inherits the Location semantic type
- Quick Create Location creates in that exact subfolder

### G. Player safety

As a non-GM:

- Quick Create context menu is unavailable
