# Adventurer’s Tome 2.1.0

Local Swedish and English analysis now combines document structure, language
evidence, campaign identities, GM choices and selected world knowledge in one
decision path. Headers, report metadata, quest status labels and ordinary
sentence starters are interpreted in context. Genuine unknown identities and
conflicting types remain available for GM review.

World starts with 10 entries. Choose 10, 20 or 30 at a time; Show more adds the
chosen amount. The preference is remembered per world/user in this browser.
Search still covers the whole permitted collection. Global Search retains its
60-result batches. Background analysis and bounded views preserve responsive
navigation; unchanged session text does not require a new analysis at reload.

World offers Original structure, By content and Custom structure. Copy an
existing folder hierarchy once and organize it in Tome without moving the
linked Foundry Actors or Items. Compendium templates are not World entries.
Known library locations can be created and linked with their source evidence;
ambiguous identities, including NPC/faction conflicts, require a decision.

## Upgrade

Update the existing `adventurers-tome` module normally. Back up the world first.
For a TestAI world: deactivate `adventurers-tome-testai`, enable Adventurer’s
Tome 2.1.0 and reload as GM. Do not run both modules together. Saved test world
settings, this user’s private decisions and local preferences transfer once.
Original test settings remain available. Other users transfer their own private
settings when they sign in. Document UUIDs, canonical links and original texts
are retained. Derived analysis caches rebuild once for the production identity;
allow Campaign Tools → Index to finish before comparing review results.

The optional Tolkien library and campaign supplements remain selectable. All
language models run locally. No new World delete/correction UI is included and
older incorrectly created entries are not automatically deleted. Language
analysis is evidence-based assistance, not a guarantee of perfect understanding.

Validated with automated regressions, real local language models, native
Foundry 13.351 tests in a copied world, and the subsequent TestAI user trial.
