# Adventurer's Tome v1.6.0-qa.26 — Unified Detail Toolbar

**Baseline:** v1.6.0-qa.25  
**Foundry target:** V13.351

## Goal

Reduce action-button noise on detail pages while preserving every existing action.

Applies to:

- Character Profile
- Quest Detail
- Rule Detail

World Detail keeps its existing dedicated qa.23 actionbar implementation.

## Layout

The detail toolbar keeps:

- Back / breadcrumbs on the left
- direct source/personal/share actions on the right
- administrative GM actions inside **GM Tools**

### Character

Direct:

- Favorite
- Character Sheet

GM Tools:

- Queue Reveal
- Show to Players
- GM Note
- Permissions
- Edit Profile

### Quest

Direct:

- Favorite
- Open Quest Journal

GM Tools:

- Queue Reveal
- Show to Players
- GM Note
- Permissions

### Rule

Direct:

- Open Rule Journal
- Send Selected Text
- Whisper Selected

GM Tools:

- GM Note
- Permissions

## QA

### B. Quest Detail

### C. Rule Detail

- Open Rule Journal remains direct

### D. Player view

- all player-visible actions remain available

### E. Responsive

- narrow Tome window wraps toolbar cleanly
- GM menu stays reachable

### F. Regression

- World actionbar remains unchanged

## Promotion rule
