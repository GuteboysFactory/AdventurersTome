# qa.43 — Swedish narrative hardening

Session 7 exposed several interacting faults, rather than a translation problem. This patch updates the shared language/discovery/resolution path for all campaigns and game systems. No campaign names are embedded in runtime rules.

## Changes

- Split coordinated people and places at `och`, while retaining named inns and name particles. Trim dangling connector words.
- Filter Swedish sentence-opening grammar and ordinary references such as `Vid`, `Boken`, and `Gruppen`.
- Recognize lower-case item/faction heads after possessive names, including delivery books and city watches.
- Normalize possessive place references only when the base name is attested and the following context is locative. Do not strip arbitrary terminal s from personal/place names.
- Expand Swedish role vocabulary and syntax, including former soldiers, smiths, couriers and relative clauses. Attached person evidence takes precedence over geographical surnames.
- Separate current and former roles. Bind role evidence to the actual occurrence assigned to each identity, so later ambiguous short names cannot donate roles to earlier full names.
- Use established personal identities when considering source-local short forms. Independent namesakes remain unresolved; no canonical merge is introduced.
- Recognize singular rumour wording, intermittent cooperation, and explicit coordinated friendship including denial/history. Cooperation does not imply membership.
- Narrow Swedish location excerpts to residence/stay predicates; merely working as a guide no longer supplies location evidence.
- Prevent a guessed type from hiding an existing exact-name identity and triggering duplicate creation. Pure lexical guesses yield to the exact match; explicit contradictory type evidence offers the existing identity for GM review.

## Existing campaign data

Reanalysis retires obsolete grammar candidates from the active queue but retains their historical audit evidence. Saved documents and GM choices are not deleted or silently retyped. An already-created person wrongly stored as Location still requires an explicit category correction via **Edit Tome Entry → Category → Contact**. Then rerun analysis and review source facts as needed.

This is a deterministic vocabulary/grammar foundation, not unrestricted language understanding. Ambiguous references and insufficient evidence still belong in Review. The exact Review count depends on the campaign's existing identities and choices.
