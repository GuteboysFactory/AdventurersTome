# Adventurer’s Tome 2.1.6

## Sessions

- The compact heading and session search stay in view. In a wide Tome window, the Campaign Explorer, session list and chronicle scroll independently.
- The reader keeps the session title and available page controls in view. In a narrow window, open a session and use **Sessions** to return to the list at the previous scroll position.
- Tome retains the search and keeps a reading position for each session during the current client session.

## Background updates

- Campaign indexing updates affected links, counters and analysis results in place. An unrelated open view stays as it was.
- When an external document change requires a full view render, Tome restores the existing view state where possible. Background updates wait while a profile is being edited.

## Upgrade

Update the existing `adventurers-tome` module via the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json). Restart Foundry and refresh browser clients. Existing campaigns require no reimport.

Verification covers 575 production tests, 52 Vault tests and an Edge browser fixture for wide and narrow Sessions layouts, scroll position, search and focus during a background link update.
