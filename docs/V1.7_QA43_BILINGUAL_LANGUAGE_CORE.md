# Bilingual narrative foundation — local QA package

This extends the existing Swedish/English foundation and keeps all matching preferences, source choices, Undo and view-continuity work. It is a deterministic, local grammar layer, not a trained language model or a complete representation of either language.

## Shared contract

The language API now supplies sentence segmentation with original offsets, title-aware personal name forms, document-head recognition, claim context and conservative source-local reference proposals. Discovery and relationship extraction use the shared helpers. Grammar has no document lookup, network access or write authority.

- Sentence boundaries retain abbreviated titles, initials and decimal numbers.
- Personal titles qualify an otherwise equal full name. A title plus a first name is not sufficient. Multiple matching authorities still require Review. Names and documents are never merged or renamed.
- Document compounds use grammatical heads, including previously unseen Swedish compounds ending in journal, bok, rapport and related heads, rather than campaign-specific titles.
- Ordinary narrative words and document references are filtered as new identities; existing explicitly named entities remain discoverable.
- English profession coverage and relative-clause role extraction are brought closer to Swedish; both accept continuing/current-role modifiers.
- Questions, quotations, reported claims, intentions and conditionals do not produce asserted profession facts. Relationships which are extracted in these contexts retain uncertainty and interpretation reasons.
- An adjacent unambiguous person reference can carry a profession to its subject. Multiple names, unknown subjects and paragraph boundaries cause abstention. Gender is not inferred from names.
- Source text, source choices, paused identities and GM campaign defaults retain authority. A language improvement does not rewrite existing private facts or delete old documents.

## Scope and limits

This is a foundation to extend with tested grammar. Arbitrary dialogue, nested attribution, free-form document titles, irony, complex temporal statements and unrestricted pronoun resolution remain incomplete. Conservative abstention can leave genuine references in Review. Quotation and uncertainty gates can suppress otherwise useful facts in the same sentence. Compound recognition is not general Swedish morphological analysis. A unique title-qualified name is linking evidence, never permission to combine two documents.

The existing UI remains unchanged. Interpretation reasons are evidence metadata rather than new claims of certainty. No external model, data download or account is required.
