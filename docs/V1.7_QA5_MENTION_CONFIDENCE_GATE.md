# v1.7.0-qa.5 — Mention Confidence Gate

**Baseline:** v1.7.0-qa.4  
**Foundry baseline:** V13.351  
**Scope:** Read-only Session/Quest semantic mention discovery

## Goal

Separate two different questions:

1. **Detection confidence** — is this text span actually a campaign mention?
2. **Identity confidence** — which canonical campaign identity does it refer to?

qa.5 adds confidence classification without enabling Campaign Link persistence.

## Confidence bands

- `deterministic`
- `high-confidence`
- `review`
- `weak`
- `suppressed`

## Detection policy

### Explicit Foundry references

`@UUID`, `@Actor`, `@Item`, `@JournalEntry`, and `@Scene` remain deterministic mention evidence when the target is visible in the current viewer-scoped Campaign Discovery snapshot.

### Multi-token exact names

Exact word-boundary matches for names such as `Röde Mattis` remain detectable.

### Proper-name single tokens

Single-token names with proper-name shape such as `Aldari`, `Bree`, and `Angmar` remain detectable.

### Lowercase single tokens

A lowercase single-token entity name such as `test` is suppressed from ordinary prose discovery unless the same page also contains an explicit visible canonical Foundry reference that anchors the same identity.

This is intentionally not a language-specific stopword list.

### Repetition

Repeated exact mentions on the same source page increase **detection** confidence only. Repetition never proves identity by itself.

### Source-local explicit anchor

If a page contains a visible explicit canonical reference for an entity and the same exact name also appears in prose, the prose mention receives a source-local canonical corroboration signal.

This strengthens the mention classification but does not enable persistence in qa.5.

## Persistence

```text
autoPersistence = false
persistenceEligible = false
```

for all qa.5 discovered mentions.

qa.5 does not create, update, or delete Campaign Links.

## QA A — lowercase generic token suppression

Use a visible Scene/entity named exactly `test` and a Session/Quest page containing ordinary prose:

```text
This is a test.
```

without an explicit Scene link.

Expected:

- no `test` row in `snapshot().mentions`
- one or more `test` rows may appear in `snapshot().suppressedMentions`
- suppressed row:
  - `assessment.disposition === "suppressed"`
  - `assessment.reason === "weak-lowercase-single-token"`
  - `assessment.persistenceEligible === false`

## QA B — proper-name single token remains detectable

Page prose:

```text
Aldari arrived at the old gate.
```

Expected:

- Aldari remains in `mentions`
- detection band = `high-confidence`
- identity result remains conservative
- with only name evidence, resolver remains `review`
- no auto persistence

## QA C — source-local explicit corroboration

Same page:

```text
Aldari arrived first.
@UUID[Actor.<AldariUuid>]{Aldari}
Later Aldari returned.
```

Expected:

- explicit row = deterministic
- prose Aldari rows are not suppressed
- prose assessment includes `source-local-explicit-anchor`
- prose disposition = `high-confidence`
- persistence remains false

## QA D — real ambiguity remains review

Two separate visible Actors with the same display name must remain distinct identities.

Expected resolver behavior:

- `decision === "ambiguous"`
- `reason === "same-name-is-not-same-identity"`
- mention disposition never becomes deterministic solely from repetition/name shape

## QA E — audit

```js
game.modules.get("adventurers-tome").api.campaignMentionDiscovery.audit()
```

Expected:

- `confidenceModel === "detection-and-identity-separated"`
- `lowercaseSingleTokensSuppressedWithoutCanonicalAnchor === true`
- `sourceLocalExplicitAnchorCorroboration === true`
- `repeatedMentionsBoostDetectionOnly === true`
- `displayNameAloneAutoLinks === false`
- `autoPersistence === false`

## PASS gate

qa.5 passes when:

- generic lowercase `test` prose noise is suppressed
- proper-name single tokens such as Aldari remain detectable
- explicit refs remain deterministic
- source-local explicit refs strengthen nearby same-name prose mentions
- repeated names never prove identity on their own
- genuine duplicate identities remain ambiguous
- no Campaign Link writes occur
