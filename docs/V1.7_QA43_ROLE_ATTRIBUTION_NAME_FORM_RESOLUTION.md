# v1.7.0-qa.43 — Role Attribution & Name-Form Resolution

## Scope

Role evidence is now attached to explicit name spans and immediately coordinated predicates. English and Swedish language rules recognize supported appositions, titles and predicates such as "works as", "was", and "arbetar nu som". Current and historical roles remain separate, with source sentences and language recorded as evidence. Current roles take precedence in the summary; historical-only summaries retain a former/tidigare marker. New World entries retain historical roles separately when a current role also exists.

The language provider has no identity or write authority. Uncertainty, negation, questions, and a different named subject must not donate a confident role to the person being described. Ambiguous pronouns are not resolved into asserted professions. Rules are deliberately bounded; this is not unrestricted language understanding.

Existing first/last-name fragments receive stronger candidate ranking, but remain unsafe for automatic linking. Existing canonical resolution and GM decisions retain authority. Source-local first-name consolidation is withheld when another established full-name candidate competes. No name-specific, campaign-specific or system-specific exceptions are used.

This patch does not add an index service, automatically merge existing identities, rewrite existing GM profiles, expand the relationship taxonomy, or publish a release. Existing source-fact review can propose supported role corrections; it is not an automatic history migration.
