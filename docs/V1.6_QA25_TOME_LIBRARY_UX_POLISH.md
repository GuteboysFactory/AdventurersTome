# Adventurer's Tome v1.6.0-qa.25 — Tome Library UX Polish

**Baseline:** v1.6.0-qa.24  
**Foundry target:** V13.351

## Goal

Bring Sessions, Quests, Rules and global Search up to the visual hierarchy established by the qa.23/qa.24 World library.

No subsystem redesign. Existing actions are preserved and relocated.

## Sessions

- remove local Search + Import Session from the page header
- surface both beside the Campaign Explorer catalog bar
- keep existing local search engine
- live result count
- X / Escape clear
- folder filtering remains authoritative

## Quests

- same library-local search/import pattern as Sessions
- status-group counts update to visible results
- empty status groups hide while filtering

## Rules

- remove the permanently expanded Rule Tools card
- expose:
  - Search Rules
  - New Rule
  - Link Existing
  - live rule count
- New Rule and Link Existing use compact popover panels
- existing create/link actions remain the canonical implementation

## Global Search

- Search toolbox moved directly below the Search page heading
- Favorites / Recently Viewed remain below it
- global Search behavior is unchanged
