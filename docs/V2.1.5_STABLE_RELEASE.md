# Adventurer’s Tome 2.1.5

## Campaign identity matching

- **This is the one** links the current source and remembers the confirmed name for the campaign. Choose **Only remember this name for this source** for a local exception. Use **Alternative names** on an identity profile to review, add or remove names.
- World search and Session and Quest analysis reuse the same names. For example, a confirmed `Edrik` also supports the Swedish genitive `Edriks`. If a saved name matches another identity, Review explains the conflict.
- Linked Foundry Actors and Tome profiles share a canonical identity. When a same-name NPC also exists outside World, analysis and the identity picker prefer the World entry. Distinct World identities remain available for review.

## Private Vault and migration

- Character sheet headers use a compact lock icon with the accessible name **Open Private Vault**.
- GMs can open Private Vault from the hover preview on Realm Guard map markers. Saved notes are read from the current GM’s own Vault.
- Realm Guard can restore missing catalog Traits such as **Stout** without interrupting login. An approved campaign migration can copy same-name documents as separate identities. Manual creation still uses the similar-name prompt.

## Upgrade

Back up the world and the previous module, then update the existing `adventurers-tome` module through the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json). Restart Foundry, refresh the browser and allow **Campaign Tools → Index** to finish. Existing campaigns require no reimport.

Automated verification covers 573 production tests and 52 Private Vault tests. Foundry VTT 13.351 remains the verified project baseline. This patch’s automated suite runs outside a live Foundry world.
