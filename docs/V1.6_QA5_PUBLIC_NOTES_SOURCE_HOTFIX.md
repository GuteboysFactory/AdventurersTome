# Adventurer's Tome v1.6.0-qa.5 — Public Notes Canonical Source Hotfix

**Previous QA:** v1.6.0-qa.4 privacy/write contract in progress  
**Verified Foundry baseline:** V13.351

## Deviation fixed

In qa.4, `notes.public` assumed all player-visible Known Information lived at:

`flags.adventurers-tome.knownInformation.html`

That is correct for Item/legacy Known Information flows, but Tome PC Character Information uses the existing canonical profile source:

`flags.adventurers-tome.profile.biography`

This caused Character Information to appear in the sheet while USL returned `unavailable`, and would also have produced a dry-run write plan targeting the wrong path.

## Fix

The USL now selects the canonical Tome public-information source per document/data model.

For Tome group-PC / Character Information Actors:

- read source: `flags.adventurers-tome.profile.biography`
- write-plan target: `flags.adventurers-tome.profile.biography`

For existing Known Information sources:

- preserve `flags.adventurers-tome.knownInformation` / `.html`

No second authoritative copy is created.
