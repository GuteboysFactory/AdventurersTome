# Adventurer's Tome v1.4.0-qa.9 — RC Gate Semantics Hotfix

**Scope:** diagnostic/release-gate semantics only. No campaign feature or data-model changes.

## Purpose

Clarify the relationship between the completed v1.3 convergence milestone and the v1.4 RC gate.

The v1.3 `convergenceAudit().qaComplete` field means that all four takeover consumers were exercised in the **current runtime session**. Those counters reset on reload and only advance when their exact import/source-action paths run.

Therefore, `qaComplete === false` does not indicate a structural regression when:

- `healthy === true`
- `structuralHealthy === true`
- takeover `misses === 0`

## Updated v1.4 release-gate output

Run:

```js
game.modules.get("adventurers-tome")?.api?.gmDock?.releaseGate?.()
```

The `convergence` section now reports:

- `healthy`
- `structuralHealthy`
- `takeoverMisses`
- `runtimeEvidenceComplete`
- `runtimeEvidenceRequiredForRelease: false`

`runtimeEvidenceComplete` mirrors the old v1.3 session-local `qaComplete` signal but is explicitly diagnostic for the v1.4 RC gate.
