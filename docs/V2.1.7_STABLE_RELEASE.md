# Adventurer’s Tome 2.1.7

## 2.1.7 update

- **Player chat:** Show a visible token’s artwork whether Foundry identifies the speaker by token, Actor, or user with an assigned character. A token visible on the current map can supply the portrait without Actor sheet access.
- **Party flag:** Right-click the flag and choose **Who can move this flag?**. Select a player and choose **Save**. This also works from the basic flag. Choose **GM only** to return control to the GM.
- Reinstall 2.1.7 from the stable manifest if that version is already installed.

## Maps and party travel

- Right-click the map to place locations, parchment notes and item markers using existing or new Foundry documents. Choose the icon, size, visibility and whether the pin has a background. The map menu can also place existing NPCs and PCs.
- Use Tome map objects as waypoints, the final destination or the party’s position. Existing Realm Guard map markers use a single **Edit marker** action. Link a Foundry scene to a marker and preview, activate, change or remove it from the map. Link scenes to Sessions, Quests and World entries from Tome.
- Drag the party flag freely and record the route it actually takes. The GM can appoint a player to move the flag, split and rejoin the party, and assign a destination separately from waypoints. Draw a leg freehand or route it via an intermediate marker.
- The GM can keep the exact destination private, share it, or share a pulsing approximate goal area. In free travel, players see the party flag and travelled trail alongside any shared goal. The GM can see the planned guide.
- Attach private encounters, checks and events to markers. When the party stops there, the GM can resolve the event, follow a branch, continue on the map or preview and activate a linked scene.
- Find the party on the map from **Party Location** on Home. Restore the saved flag, route and goals on GM sign-in. Undo the latest movement or route edit. When the party leaves a waypoint, earlier legs fade to translucent grey.
- Open travel history from Sessions, My Chronicle or Campaign Tools. The GM can remove several unlinked legs or archived routes at once. GMs and players can mark older routes with personal colors.

## Portraits and tokens

- Use Tome’s Token Builder through the character profile or Foundry Actor sheet. Click the sheet portrait or drop an image on it to open Tome’s Portrait Editor. Group, Home and the sheet share the same display choice of full artwork, cropped portrait or token image.
- Choose a frame shape separately from its texture, colors and thickness. Use a frame-free full image or create a new portrait crop. Export still images or animated glow, fire, frost, sparks and arcane effects with a still poster.
- Saving the token image updates the Foundry prototype and placed copies across scenes where the user has permission. A save option lets users retain custom token artwork. Actor artwork also updates in Foundry’s Actors list and in Tome’s search and linked World views.
- New tokens keep their artwork upright by default. Rotation can be overridden.

## Chat, permissions and scenes

- Send document links, selected text, tables or images to chat or as a whisper from Foundry while Tome is closed. The available recipients and content respect document and page access.
- Optional speaker portraits have configurable shape and size. The Chronicler represents a GM speaking as themselves. Shared documents can display cards with permitted images and details.
- Select multiple entries in World or Foundry’s sidebars. Review who can see the selection and their access levels before applying ownership changes. Foundry sidebar tools also support moving, JSON export and deletion.
- Use compact scene navigation with folders and player access controls. Opt in to new-scene defaults for token vision, global lighting and grid settings.

## Quests and GM notes

- Change a quest between **Active**, **Dormant**, **Completed** and **Failed** from the compact status dropdown.
- Select a token and use **GM Notes** from its HUD or the configurable **Write Private Vault note** shortcut. The default uses Ctrl with the physical **<** key on Nordic keyboards. Both open the private editor ready for typing. Hover over a token or map note for a GM-only preview.

## Upgrade

Update the existing `adventurers-tome` module via the [stable manifest](https://raw.githubusercontent.com/GuteboysFactory/AdventurersTome/main/channels/gold/module.json). Restart Foundry and refresh browser clients. Existing campaigns can continue without reimporting their data.
