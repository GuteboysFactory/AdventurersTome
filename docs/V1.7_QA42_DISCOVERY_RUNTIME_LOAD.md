## Reproduced duplicate work

Universal Discovery previously starts a complete scan for every caller, without sharing an in-flight scan. Registry rebuilt schedules another complete scan with compendiums and adapters. Initial lifecycle writes and concurrent consumers can overlap. Tests reproduce eight overlapping callers: before policy executes eight independent world/pack/adapter pipelines; current policy runs one shared pipeline for equivalent default calls. A real registry event during the scheduled scan is retained and produces one trailing fresh pass. Later manual scans remain available; different viewer IDs/roles, includeCompendiums options and custom adapter contexts are not mixed.

Embedded Item resolution previously enumerated every Actor and embedded Item and searched the result even for UUIDs which cannot be Actor Items. Previous live instrumentation recorded 1343 passes and 37604 actor visits. It now parses an exact Actor.<id>.Item.<id> identity and queries only the corresponding Actor collection and embedded Item collection. No global cache is introduced: changes/removal and live permission checks remain current. Enumeration is retained for explicit embedded-item lists/audits.
