# qa.42 — Recent decisions and source-fact review

Local test patch. Keep version 1.7.0-qa.42; validate in Foundry before publication.

## Behaviour

- Undo opens a GM-only picker containing the latest ten recorded Review decisions and source-fact corrections, with label, source and time. Opening or cancelling it performs no writes. No radio option is preselected.
- History lives in the existing world learning state and survives reload. Recording starts with this patch; earlier decisions have no recoverable before-state and are not fabricated as undoable history.
- Independent older decisions can be undone directly. Later dependent decisions must be undone first. A changed source decision or manually edited corrected profile blocks stale undo. Undo of creation preserves the document. A storage failure restores a removed canonical link or corrected profile; a failed derived refresh does not roll back a successful authoritative undo.
- Completed Review cards retain their height and display the saved choice plus an Undo button opening the same picker. Navigation removes temporary slots.
- Review source facts is available on World journal candidates and under a World entry's GM Tools. Choose a recorded source when opening from World. It freshly reads that source, shows existing values, proposals and supporting excerpts, and changes only explicitly checked fields.
- Current correction coverage: a clearly attached profession can correct an existing subtitle or Role / profession field. Old faction/location/relation fields containing matching copied source excerpts can be selected for removal. It does not infer replacement canonical relationships, rename identities or merge Actor/Contact documents.
- Existing fields may contain GM edits, so all proposed checkboxes start unchecked. Other facts, notes, visibility and profile data are preserved. The source and profile are rechecked before approval is applied. Accepted corrections are themselves recorded in the ten-decision history.
- New automatic World profiles label non-profession briefing text as source excerpts and record origin/source UUID. English and Swedish uncertainty prefixes prevent a rumoured appositive profession from being stored as a definite role. The previous subject-ownership guard remains in force.

## Validation

The full regression run passed 430 tests. After final safeguards, 53 focused tests passed, including two additional cases (432 distinct tests validated): authoritative undo with failed derived refresh, and correction rollback/manual-edit protection. The suites include Session 4–5 identity continuity, independent namesakes, bilingual attribution/rumour cases with unrelated names, relation certainty/negation/time, permission restrictions, startup work, single-render Review behaviour, history/reload/dependencies, view continuity and source corrections. Manifest/URL and 92 ES-module plus one vendor-script syntax checks passed. Final toolbar classification is a UI-only change.

Browser dialog appearance and real Foundry lifecycle still require live QA. These are deterministic language rules with conservative abstention; the patch does not provide general natural-language understanding. There is no shared indexing service or new startup analysis pass.

## Live QA before a new Session

1. Install this ZIP and reload. Check startup remains fast.
2. Resolve two independent Review decisions. Each saved slot should show its label and Undo without shifting the following choices.
3. Click Undo: the list should open without changing anything. Cancel once, then open it again and undo an older independent choice. Reload and check the remaining history. Dependent rows should explain why they cannot yet be undone.
4. On Orren's candidate in Session 5, open Review source facts. Check the evidence supports former scout, select the old captain fields you want corrected, and inspect any proposed excerpt removals. Apply; confirm unrelated notes remain. Confirm the correction appears in Undo.
5. Reanalyse Sessions 4–5. Check remembered identity choices, source attribution, rumours/negation/historical relationships and UI position. Test equivalent Swedish text with different names.
6. When these checks pass, create the next Session to test continuity with genuinely new text rather than repeatedly reusing the old fixture.
