# Adventurer's Tome v1.6.0-qa.21 — Native Quick NPC Provider Bridge

**Baseline:** v1.6.0-qa.20 startup hotfix  
**Foundry target:** V13.351  
**Companion Realm Guard QA:** v1.11.0-qa.10

## Goal

Allow system-specific native Quick NPC tools to replace Tome's generic Quick NPC form without coupling Tome Core to a specific system implementation.

Tome asks the active system adapter for a native Quick NPC provider.

- provider available -> delegate to the system's native UI
- provider unavailable -> use qa.19 generic schema-based creator
- provider failure -> fail soft and open the generic fallback

## Adapter capability

New capability:

`nativeQuickNpc`

Public helper:

```js
game.modules.get("adventurers-tome").api.adapters.nativeQuickNpc()
```

Provider contract:

`adventurers-tome-native-quick-npc-provider` v1

## Realm Guard

Realm Guard v1.11.0-qa.10 exposes:

```js
game.realmGuard.quickNpc
```

with:

- `open()`
- `openGroups()`
- `createFromTemplate()`
- `matches()`
- `resolveBestTemplate()`

The Tome Realm Guard adapter bridges this provider. Tome does not import Realm Guard implementation files or template metadata.

## QA

### A. Provider availability

After updating Realm Guard to v1.11.0-qa.10 and Tome to v1.6.0-qa.21:

```js
const at = game.modules.get("adventurers-tome").api;
await at.quickNpc.providerInfo();
```

Expected:

- providerId = `realm-guard`
- systemId = `realm-guard`
- label = `Realm Guard Quick NPC Library`
- capabilities include `openLibrary`

### B. Tome button delegates natively

Open Tome -> World -> Quick NPC.

Expected:

- Realm Guard's full Quick NPC Library opens
- template cards are visible
- search works
- category/culture/competence filters are present
- Group Templates is available
- Tome generic Name/Concept/Rank form does not open

### C. Template create

Create one NPC from a Realm Guard template.

Expected:

- normal editable Realm Guard NPC Actor is created
- Realm Guard template provenance is preserved
- Actor sheet opens according to Realm Guard native behavior

### D. Generic fallback remains available

As GM:

```js
await at.quickNpc.open({ forceGeneric:true })
```

Expected:

- qa.19 generic schema-based Quick NPC form opens
- preview/apply contract remains functional

### E. Player safety

As a non-GM, Tome -> Quick NPC remains unavailable and direct API call is blocked.

### F. Audit / regression

```js
at.quickNpc.audit()
```

Expected:

- healthy = true
- npcCreationContract = true
- nativeProviderCapability = true

Then run full v1.6 regression.

## Promotion rule

qa.21 passes when Realm Guard native delegation, template creation, generic fallback, GM safety and the full prior regression all pass.
