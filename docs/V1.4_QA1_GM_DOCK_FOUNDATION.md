## 1. Startup / visibility

- [ ] Install/update to v1.4.0-qa.1.

## 2. Placement / persistence

- [ ] Drag the Dock using the grip.
- [ ] Dock remains within the visible viewport.
- [ ] Reload the world: Dock returns to the GM user's saved position.
- [ ] Right-click the grip: Dock resets to its default lower-center placement.
- [ ] A second GM user is not forced to use the first GM's saved position.

## 3. Current context

- [ ] Open a Tome Actor/Character entry: Dock shows that context.
- [ ] Open a Tome Session/Quest/World/Rule entry: Dock follows the active Tome context.
- [ ] Open a supported Foundry sheet while Tome has no stronger active context: Dock can follow the Foundry document.
- [ ] With no explicit supported context, active Scene or campaign context is shown safely.
- [ ] Rename a linked source: Dock resolves the new canonical name after normal Foundry/Tome refresh.
- [ ] No duplicate context data model is created.

## 4. Pin / unpin

- [ ] Pin a context.
- [ ] Navigate elsewhere: pinned context remains active in Dock.
- [ ] Unpin: Dock returns to normal context resolution.
- [ ] Reload while pinned: UUID-backed pin survives and resolves correctly.
- [ ] Delete a pinned source: Dock falls back safely instead of showing a false live source.

## 5. Contextual Private Vault

- [ ] Add/edit/save a private note.
- [ ] Reopen from Tome/supported source: same UUID-backed private record is shown.
- [ ] Player client receives no GM-private note content.

## 6. Quick Capture

- [ ] No parallel Quick Capture storage is created.
