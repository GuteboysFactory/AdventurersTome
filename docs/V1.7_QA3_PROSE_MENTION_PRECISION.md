## Live qa.2 finding

Controlled Session QA proved the scanner pipeline works:

- explicit Foundry ref detected

- cleanup returned the runtime mention snapshot to zero rows

The same QA page also exposed false-positive prose matches against generic lowercase words such as `test` when a visible campaign entity had the display name `Test`.

## Fix

Single-token entity names are now matched case-sensitively in prose.

Examples:

- entity `Aldari` matches prose `Aldari`
- entity `Test` does not match ordinary lowercase word `test`
- multi-word canonical names continue to use case-insensitive exact phrase matching

This is a discovery-precision rule only. It does not change identity resolution, privacy, Campaign Link persistence or authority.
