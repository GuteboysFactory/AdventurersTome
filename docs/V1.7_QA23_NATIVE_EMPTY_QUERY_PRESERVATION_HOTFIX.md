# v1.7.0-qa.23 — Native Empty Query Preservation Hotfix

**Baseline:** v1.7.0-qa.22  
**Foundry baseline:** V13.351  
**Scope:** preserve an explicitly empty native Quick NPC template query all the way through Tome's Quick NPC bridge.

## Live QA finding

qa.22 correctly separated the candidate Actor name from the intended native template query at Campaign Intelligence and Universal Folder Quick Create, but the final Quick NPC bridge still used:

```js
initialQuery: clean(options.initialQuery || options.name)
```

Because an explicit empty string is falsy, the candidate name was reintroduced as the native template search term.

Observed result:

```text
Captain Varek
0 / 443
No NPC templates match this search.
```

## Hotfix behavior

The native Quick NPC bridge now distinguishes:

```text
initialQuery property absent
→ fallback to options.name

initialQuery explicitly provided as ""
→ preserve ""
```

Campaign Intelligence Character/NPC creation therefore opens the full native template library while still preserving the confirmed candidate as the created Actor name.

## Scope boundary

- Only the native NPC bridge changes.
- Item, Location, Contact, Faction and Lore creation are untouched.
- qa.22 Universal Folder Quick Create behavior remains unchanged.
- qa.21 completion-aware waiting remains unchanged.
- qa.20 canonical UUID and Campaign Link convergence remain unchanged.
- No automatic template choice is introduced.

## Primary QA

1. Confirm a Character/NPC candidate such as `Captain Varek`.
2. Click **Create & Link**.
3. Choose **Character / NPC**.
4. Continue to native creation.

Expected:

- Quick NPC Library opens with the full template set visible.
- Search field is empty.
- No manual Clear action is required.
- Selecting any template creates an Actor named `Captain Varek`.
- Tome continues through canonical UUID + Campaign Learning + Campaign Link convergence.

## Regression

- Native Quick NPC callers that omit `initialQuery` still receive the existing name-based search fallback.
- Explicit non-empty `initialQuery` values still filter normally.
- Item/Location/Contact/Faction/Lore Create & Link preserve their current name-prefill behavior.

## PASS gate

qa.23 passes when Campaign Intelligence Character/NPC Create & Link opens Realm Guard Quick NPC unfiltered, preserves the candidate as Actor name, and completes canonical convergence with no manual Clear step.
