# QA.4.16 — One launcher for opening and resting Tome

The title-bar X animates the live Tome window into the existing draggable launcher. Clicking that same launcher restores it. The animation reads the current button rectangle independently for minimizing and restoring, including when the launcher is moved while Tome is parked. There is no second bottom bar.

The parked launcher reserves space for a small complete-close X. This is a separate sibling button with an accessible label, positioned with the launcher's existing movement callback. It follows drag, viewport clamping and the original right-click position reset without polling or observers. Complete close removes the added control and returns the launcher to its ordinary appearance.

Existing draft/scroll/window-position preservation, deferred background refresh, reduced motion and close-during-animation cleanup remain in effect. Check dragging before minimizing and while parked, reopening from the new position, keyboard operation, resizing the viewport and complete close. No campaign writes or reimport needed.
